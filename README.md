# Pravo Story — clean OGSR port

Это отдельная чистая база OGSR. Она не использует AMK как основу и не изменяет
исходный проект в `C:\amk\gamedata`.

## Что где лежит

- `story/gamedata` — только авторский сюжет, ресурсы и минимальные OGSR-хуки.
- `spawn-clean` — генерируемый исходник `all.spawn`; вручную его не править.
- `game` — локальная тестовая сборка OGSR.
- `engine` — официальный репозиторий OGSR Engine.
- `tools` — воспроизводимая сборка и запуск.

## Сборка

Из PowerShell:

```powershell
cd C:\amk\ogsr-project
.\tools\build_all.ps1
```

Команда заново создаёт чистый spawn на основе оригинального Shadow of
Chernobyl, переносит только объекты этого сюжета, компилирует `all.spawn` и
разворачивает результат в `game/gamedata`.

## Запуск новой игры

```powershell
.\tools\run_new_game.ps1
```

Для проверки изменений в spawn всегда нужна новая игра. Старые сохранения AMK
с этой сборкой несовместимы.

Оригинальный сюжет ТЧ отключается при сборке: убирается автоматическая выдача
его заданий из info portions, блокируются оригинальные сюжетные диалоги,
отключаются обработчики level_tasks и основные сюжетные sr_idle/sr_cutscene/
sr_sound_act-триггеры. Общие разговоры, торговля, аномалии и переходы сохранены.
В активном списке циклических заданий оставлены только авторские задания
торговца Радара. В Припяти удалены оригинальные сюжетные сталкеры и респавнеры
военных, Долга, Свободы и Монолита. Оригинальные ID сохранены в конфигурациях,
чтобы условия симуляции не ссылались на отсутствующие определения.

На Радаре пси-поля Выжигателя отключены в спавне. Для существующих сохранений
контроллер при входе на Радар устанавливает `bar_deactivate_radar_done`,
завершая оригинальную логику пси-зон. Авторский эффект возле травы независим
от этой системы и сохраняется.

## Уже перенесённая цепочка

Припять (детсад и побег) → раненый Макар → отряд Свободы → переход на Радар →
лагерь Свободы → собаки → Макар и трава → зомбированные → Кэп на Барьере → Лукаш.
Также перенесены
торговец Радара и повторяемые задания на артефакты.

После отчёта о зомбированных командир Радара отправляет героя к Кэпу на Барьере,
а Кэп — к Лукашу на базу Свободы. Это два отдельных задания с метками PDA.
В старом сохранении после уже сданных зомбированных нужно ещё раз поговорить
с командиром Радара: появится короткий диалог «Куда мне дальше?».
Старые сюжетные бои на Складах, волны Монолита, группа Черепа и шпионская
сцена отключены; очистка существующих сохранений проходит постепенно через
ALife release. Кэп и Лукаш сохраняют оригинальные модели, имена и story IDs.
Бар и новые задания Лукаша пока не подключены.

## Отладка

По умолчанию включены бессмертие и бесконечная выносливость. В меню паузы:

- F1/F2/F3 — раненый Макар, гастроном, переход на Радар.
- F4/F5/F6/F7 — лагерь Радара, собаки, трава, зомбированные.
- F8 — возврат к предыдущей точке, включая другую локацию.
- F9 — АК-74, патроны и медикаменты.
- F10 — переключить бессмертие и выносливость (сохраняется в сейве).
- F11/F12 — Кэп и Лукаш на Армейских складах.

Перед телепортом перезаписывается только специальный слот
`pravo_debug_before_jump`. Телепорты не меняют сюжетные флаги.
Полностью отключить инструменты: `enabled = false` в
`story/gamedata/config/pravo_debug.ltx`, затем развернуть overlay и перезапустить
игру. Исходники русских XML находятся в `tools/assets` (UTF-8), сборка переводит
их в Windows-1251 для игры.

Мёртвый город пока намеренно не включён: сначала для него нужно отдельно
собрать совместимый с чистым OGSR `game.graph`, а уже затем добавлять переходы.
