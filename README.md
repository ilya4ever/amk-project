# Pravo Story — clean OGSR port

Это отдельная чистая база OGSR. Она не использует AMK как основу и не изменяет
исходный проект в `C:\amk\gamedata`.

## Что где лежит

- `story/gamedata` — только авторский сюжет, ресурсы и минимальные OGSR-хуки.
- `spawn-clean` — генерируемый исходник `all.spawn`; вручную его не править.
- `game` — локальная тестовая сборка OGSR.
- `engine` — официальный репозиторий OGSR Engine.
- `tools` — воспроизводимая сборка и запуск.

## Сборка

Из PowerShell:

```powershell
cd C:\amk\ogsr-project
.\tools\build_all.ps1
```

Команда заново создаёт чистый spawn на основе оригинального Shadow of
Chernobyl, переносит только объекты этого сюжета, компилирует `all.spawn` и
разворачивает результат в `game/gamedata`.

## Запуск новой игры

```powershell
.\tools\run_new_game.ps1
```

Для проверки изменений в spawn всегда нужна новая игра. Старые сохранения AMK
с этой сборкой несовместимы.

Оригинальный сюжет ТЧ отключается при сборке: убирается автоматическая выдача
его заданий из info portions, блокируются оригинальные сюжетные диалоги,
отключаются обработчики level_tasks и основные сюжетные sr_idle/sr_cutscene/
sr_sound_act-триггеры. Общие разговоры, торговля, аномалии и переходы сохранены.
В активном списке циклических заданий оставлены только авторские задания
торговца Радара. В Припяти удалены оригинальные сюжетные сталкеры и респавнеры
военных, Долга, Свободы и Монолита. Оригинальные ID сохранены в конфигурациях,
чтобы условия симуляции не ссылались на отсутствующие определения.

## Уже перенесённая цепочка

Припять (детсад и побег) → раненый Макар → отряд Свободы → переход на Радар →
лагерь Свободы → собаки → Макар и трава → зомбированные. Также перенесены
торговец Радара и повторяемые задания на артефакты.

Активный сюжет пока намеренно заканчивается на Радаре. Армейские склады,
Барьер, Лукаш и бар Свободы будут подключаться отдельным следующим этапом.

Мёртвый город пока намеренно не включён: сначала для него нужно отдельно
собрать совместимый с чистым OGSR `game.graph`, а уже затем добавлять переходы.
